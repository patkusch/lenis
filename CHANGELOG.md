# Changelog

What changed and when, newest first. This project does not have numbered releases, so the entries are grouped by month.

## 2026-10

- Dependencies updated within their allowed ranges (puppeteer, vite, source-map-js). Declared the Node version the tests run on.

## 2026-09

- Offline tests for the coach and the voice analyzer.

## 2026-08

- First version: a calming companion that sets its pace from the sound of your voice. It has a consent step before it starts, an adaptive pace, a session and a check-in.
- Slower default pace and a narrower sweep to reduce dizziness; a speed stepper; guidance for closed eyes. Movement is limited to side to side and up and down.
- An "About the evidence" section. A coach that runs on the device with no outside service, and a route to crisis help.
- A recovery mode, with symptom tracking and a summary a clinician can read.
- Fixed review findings: the crisis text-message link, keeping the interim transcript, and loading audio only when needed.
